# Power BI Final Project 📊

## 📌 Overview
This is my  Power BI project, where I built an **interactive dashboard** to analyze and visualize data insights.  
The project demonstrates data cleaning, modeling, and visualization skills using Power BI.

## 🗂️ Project Files
- `FinalProject.pbix` → Power BI Dashboard file.
- `data/` → Raw dataset used in the project (CSV/Excel).
- `images/` → Screenshots of the dashboard.

## 📊 Dashboard Preview
![Dashboard Screenshot]("D:\BA\project\power bi\data_pro_survey\dashboard.png")

## 🚀 Key Features
- Data cleaning & transformation in Power Query.
- Interactive charts (bar, line, pie, map).
- KPI cards to highlight key metrics.
- Filters & slicers for dynamic exploration.

## 🛠️ Tools Used
- **Power BI Desktop**
- **Excel / CSV** (data source)

## 🎯 Insights
- Sales trend analysis by year & region.
- Top performing categories.
- Revenue distribution across different time periods.
- Customer behavior analysis.

## 💡 How to Use
1. Download the `.pbix` file.
2. Open it using **Power BI Desktop**.
3. Explore the dashboard and interact with filters.
